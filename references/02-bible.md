# 02 · The bible (`00-bible/`)

> **Goal** — one source of truth for story, style, voice and assets before anything is generated.
> **In** — the study · **Out** — the six files below (starters in `templates/bible/`). Keep each one short and decisive.

## BRIEF.md
Product in one line · audience · markets/countries · language + dialect · the promise (3–5 bullets) · tagline ·
CTA + URL · deliverables (10 stories 1080×1920 ~20–28 s, YouTube 1920×1080 ~5 min) · screens we film / avoid.

## The scenario must be unique per brand
Invent **one world with a deadline and a number** so the series has a thread and a countdown:
- a recruiting app: «30 يوم للافتتاح» — a resort must hire 214 people in 30 days; stories are D‑30 … D‑0.
- a coaching app: a coach's week drowning in WhatsApp check-ins → one place.
Rules: a named hero who uses the product (e.g. the recruiter); one supporting character per story, each tied
to ONE feature; real professions/places of the market; the last story pays off the countdown (opening day, team photo).
Never reuse a previous project's story beats.

## BRAND-LOCK.md
Two worlds: **collage world** (story beats, characters, objects) + **product world** (exact UI).
Sections: colour tokens table · type (headline font/weight/sizes, captions, name tags) · collage grammar · motion
grammar · characters · icons rule · never-list. If a prompt or component disagrees, BRAND-LOCK wins.

## STORY.md
Cast table (name, role, outfit, tools, feature, score/data) · demo data (job titles, numbers, emails exactly as
the app renders them) · ST01–ST10 (one paragraph each: collage beat → live UI beat → headline) · YouTube chapter
table (YT_00 … YT_14, timecodes, feature, UI screens).

## VO (VO-SCRIPTS.md or VO-MASTER.md)
Header: accent, narrator (gender/age/tone), pace (~2.1–2.2 words/s), English terms kept in Latin
(CV, AI, Auto-Fill, tab…), brand pronunciation. Then one code block per wav file: `ST01.wav`…`ST10.wav`,
`YT_00.wav`…`YT_14.wav`. New line ≈ 0.5 s pause, `…` = breath. Captions are generated from these exact lines.

## ASSET-MANIFEST.md
Every ID (CHR-, PST-, TL-, SK-, OBJ-, PP-, DEV-, VID-, MUS-, VO) → where it's used → ✅. Plus the **minimum set to
build the pilot story**, so Adem can start generating before the whole list is done.

## CLIENT-QUESTIONS.md
`| # | Question | Default used now | Answer |` — names/spelling, claims & stats, CTA URL, unreleased features,
third-party logos (Google/Outlook → text only), character style, narrator, language versions.
